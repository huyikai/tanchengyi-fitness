# 谭成义健身资料收集库 — 设计说明

日期：2026-08-12  
状态：已确认（对话定稿）

## 1. 目标与边界

### 目标

- **自用**：收集、整理与谭成义相关的健身公开资料，便于日后查阅与跟练。
- **开源**：仓库公开可读；必须醒目说明维护者**不是谭成义本人**，且与其团队/品牌**无官方关联**。
- **Agent 驱动收集**：由 Agent 借助本地浏览器做粗扫/细扫并落库；维护者负责启动、登录放行与审核，而不是手工逐条填表。

### 优先级（重要）

1. 收集与落库规范 + 粗扫产出（当前首要）
2. 细扫原料库 → 正式条目
3. 结构随数据再定稿
4. VitePress 等静态站点（**后置**，第一版不做）

### 内容范围

| 纳入 | 说明 |
|------|------|
| 训练计划 / 课表 | 动作、组数、频率等整理 |
| 动作技术要点 | 发力、常见错误等 |
| 饮食 / 补剂 | 相关公开表述的整理 |
| 出处与截图 | **挂在条目详情内**，不单独做顶层类目；出处优先本人/官方向链接；截图仅辅助理解 |

**不纳入（第一版）**：个人打卡/训练日志；付费线下课破解或全文搬运。

### 明确不做（第一版）

- VitePress / 任何 SSG 站点搭建
- 细扫批量写满 `inbox/raw/`（须粗扫审阅通过后）
- 一次性定死深层信息架构（部位树、周期树等）
- 保证打穿全部登录墙或抓全平台内容

## 2. 收集策略：粗扫 → 细扫

冷启动不采用「一条条给主题」或「一条条给链接」为主流程。

### 2.1 粗扫（当前主战场）

目标：建立地图，不深挖正文。

完成标准（A+B+C 同时具备初稿）：

| 产出 | 文件 | 内容 |
|------|------|------|
| A 主题地图 | `research/coarse/taxonomy.md` | 临时二级类目 + 一句话定义；`status: draft` |
| B 账号/栏目图 | `research/coarse/source-map.md` | 平台、账号、主页链接、是否疑似官方向、主要栏目 |
| C 代表锚点 | `research/coarse/anchors.md` | 每类 3～5 条：标题 \| 平台 \| URL \| 入选原因；不写长摘录 |

另产：`research/coarse/blocked.md`（登录墙/风控未拿到的清单）及必要列表页/主页截图。

维护者审阅后冻结 **`taxonomy-v0`**（允许日后改名/合并，作为细扫入口）。

### 2.2 细扫（粗扫通过后）

- 按类目批次：对锚点及扩展来源写入 `inbox/raw/`（一条源内容一篇）。
- 截图落入 `inbox/assets/`，在条目内引用。
- 状态：`captured` → `noted` → `curated`（或 `abandoned`）。
- 足够原料后，再合成 `content/` 下正式主题条目；出处与截图写在正式条目详情中。

### 2.3 与「两阶段条目」的关系

- 粗扫 ≈ 定地图（taxonomy / source-map / anchors）
- 细扫 ≈ raw 原料 → curated 正式条目
- 站点 ≈ 有一批 `content/` 后再挂（本设计范围外的后续工作）

## 3. Agent 协作与本地浏览器

### 3.1 分工

| 角色 | 职责 |
|------|------|
| 维护者 | 启动粗扫/细扫；在自动化浏览器中完成平台登录；审地图与锚点；决定是否进入下一阶段 |
| Agent | 驱动本地 Chrome 采集；按规范写仓库文件；标注状态与 blocked；不定死深层结构 |

### 3.2 本地浏览器（可行且纳入默认通道）

环境具备 Cursor Browse（Playwright 本地模式）：使用本机 Chrome，可导航、点击、滚动、截图、抽取页面文本。

| 能力 | 预期 |
|------|------|
| 打开页面、交互、截图、抽文本 | 可用 |
| 缓解部分登录墙 | 部分可用：可从主 Chrome 复制 cookie；仍常需维护者在自动化窗口手动登录一次 |
| 完全绕过反爬 / 稳定全站抓取 | **不承诺** |
| 粗扫（搜账号、列栏目、标题+链接、截列表） | 适合 |
| 细扫长视频逐字稿、强风控页 | 视平台；失败则降级 |

### 3.3 浏览器流程原则

1. 粗扫/细扫**默认**走本地浏览器，不以无头裸爬为主通道。
2. 遇登录墙：Agent **暂停**，请维护者登录该自动化浏览器后再继续。
3. 遇验证码/风控：记入 `blocked.md`，换公开页或可访问链接，不硬刚整批中断。
4. 浏览器只是采集通道；落库格式仍服从本设计中的文件规范。
5. 出处优先本人/官方向；二创/搬运号不得标为官方出处。

## 4. 仓库结构

免责说明放在 **`README.md`**，不单独建 `DISCLAIMER.md`。

```text
tanchengyi-fitness/
├── README.md                 # 项目说明 + 免责声明（醒目）
├── docs/
│   └── collecting.md         # Agent/人共用的收集规范（含浏览器流程）
├── templates/
│   ├── raw-entry.md          # 细扫原料模板
│   └── curated-entry.md      # 正式条目模板
├── research/
│   └── coarse/               # 粗扫产出
│       ├── taxonomy.md
│       ├── source-map.md
│       ├── anchors.md
│       ├── blocked.md
│       └── assets/
├── inbox/
│   ├── raw/                  # 细扫原料
│   └── assets/
└── content/                  # 正式整理（细扫中后期再长；类目可改）
    ├── plans/
    ├── technique/
    └── nutrition/
```

原则：

- 目录保持浅；类目以 `taxonomy.md` 为准，可后调。
- `content/` 下三类仅为占位，**不定死**信息架构。
- raw 记录不轻易物理删除；废弃用 `abandoned` 状态。

粗扫截图命名：`research/coarse/assets/YYYYMMDD-简短说明.png`。

## 5. 落库格式（Markdown + frontmatter）

采用「Markdown 原料 + 正式条目」，便于 Git 与日后挂站点。

### 5.1 细扫 raw（`templates/raw-entry.md` 为母版）

建议字段：`id`、`platform`、`title`、`url`、`account`、`official_likelihood`、`captured_at`、`status`、`taxonomy_hints`、`notes`（要点摘要，非全文搬运）、截图相对路径。

### 5.2 正式条目（`templates/curated-entry.md`）

建议字段：`title`、`type`（plans|technique|nutrition）、`sources[]`（官方向优先）、`status`、正文结构含「要点 / 出处与截图」。

第一版实现以模板文件为准；粗扫阶段可先只落 `research/coarse/*`。

## 6. 免责与版权（README）

README 开篇须包含：

- 个人学习向整理；维护者不是谭成义本人；与其团队/品牌无官方关联。
- 内容为公开渠道笔记与摘要，不保证完整或最新。
- 不提供医疗/训练安全保证；跟练风险自担。
- 出处优先本人/官方向；截图仅理解辅助。
- 权利方要求删除时配合处理（可留联系方式占位）。

Agent 收集约束：

| 做 | 不做 |
|----|------|
| 标题、链接、要点摘要、必要截图 | 整段搬运文案/字幕当长期正文 |
| 优先官方向账号与链接 | 将二创/搬运号标为官方 |
| 付费墙：能看则要点+来源；不能则 `blocked` | 破解付费或分享付费全文 |

开源许可建议：仓库结构与自撰文档可用 **MIT**；第三方截图与引述**不在 MIT 授权范围内**，README 注明版权归原权利人。

## 7. 第一版交付与成功标准

### 交付

1. 仓库骨架：`README`（含免责）、`docs/collecting.md`、`templates/`、空目录占位。
2. 跑通粗扫一轮：本地浏览器 + Agent 写出 taxonomy / source-map / anchors（及截图、blocked）。
3. 维护者审阅 → 冻结 `taxonomy-v0`。

### 粗扫验收

- A/B/C 初稿齐全；个别类目锚点不足须在文档中写明缺口。
- `blocked.md` 如实记录失败项。
- README 免责醒目，访客能立刻看到「非本人」。

### 后续（本设计之后另开计划）

- 细扫批次落 `inbox/raw/`
- 合成 `content/`
- 可选 VitePress 展示

## 8. 决策记录（摘要）

- 形态：日后静态站（VitePress），但**现在不做站**，先收集。
- 顶栏类目：计划 / 技术 / 饮食；出处与截图在详情内。
- 落库：Markdown + inbox；两阶段 raw → curated。
- 采集：粗扫（A+B+C）→ 细扫；Agent + 本地浏览器。
- 免责：写入 README，不单独文件。
