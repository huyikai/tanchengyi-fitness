## 要点

- **合集**：抖音「私教跟练系列！！」**7 集**。自称保姆级、少剪辑的长视频。优先看本人号；三平台同主题对照，不要当成多套课表。不要和 [焚决](./fenjue.md) 并成一张动作表。
- **分集顺序（据抖音合集侧栏 + 标题「第 n 期」）**：

| 序 | 部位 | 约时长 | 本人入口 | 章节动作名（页面「章节要点」，非口播课表） |
|----|------|--------|----------|------------------------------------------|
| 1 | 背 | 约 49:11 | 抖音 `7647176615788911793`；B 站 `BV1HR7o6CE8q` | 训练前的准备 → 健腹轮与泡沫轴 → 跪姿肘屈伸 → 直臂下压 → 单手绳索划船 → 对握高位下拉 → 坐姿绳索划船 → 绳索曲臂下压 → 龙门架反向飞鸟 |
| 2 | 手臂 | 约 38:44 | 抖音 `7648931004442846193`；B 站 `BV1GzEg6wEVb` | 单手绳索臂屈伸 → 仰卧杠铃臂屈伸 → 坐姿绳索二头弯举 → 仰卧哑铃肩伸位弯举 → 单手绳索肩屈位臂屈伸 → 坐姿绳索内旋位弯举 |
| 3 | 胸 | 约 38:24 | 抖音 `7650309381392785073`；B 站 `BV1ZxEk6cEv1` | 热身 → 双杠臂屈伸 → 坐姿平推 → 上斜推胸 → 绳索夹上胸 → 肩部训练（该集末章，不要并进第 4 集肩课表） |
| 4 | 肩 | 约 39:47 | 抖音 `7651943506576442225`；B 站 `BV1csj36CEf9` | 肩部热身 → Trx激活 → 俯身哑铃肩伸（后束） → 坐姿反飞鸟（后束） → 哑铃推肩 → 哑铃侧平举（中束） → 哑铃前平举（前束） |
| 5 | 腿 | 约 52:57 | 抖音 `7655982129109198321`；B 站 `BV1RjTT6FEKo` | 热身 → 小腿训练 → 内收肌训练 → 保加利亚深蹲 → 哑铃硬拉 → 屈髋抬腿 → 俯身腿弯举 |
| 6 | 腹 | 约 16:48 | 抖音 `7657365167379023973`；B 站 `BV1z8Th6BEij` | 悬垂举腿 → 仰卧卷腹 → 健腹轮 |
| 7 | 手臂（二） | 约 13–14 分钟量级 | 抖音 `7658495365934683493` | 绳索臂屈伸 → 坐姿绳索弯曲 → 仰卧杠铃臂伸与站姿杠铃弯举类（章节名在页上被截断）。标题写二练也可当一练参考。 |

- **本条没有**：组数、组间歇、负荷；第 7 集章节摘要里的次数不是处方。需要跟练打开对应长视频。器械细节见 [器械合集](./gym-machines.md)。
