# 主题地图（粗扫 A）

已审阅冻结为 taxonomy-v0，细扫入口以此为准（仍可后续修订）。

> 临时二级类目已冻结为 v0；细扫中若发现缺口可再修订并升版本。

## 类目

| ID | 名称 | 一句话定义 | 备注 |
|----|------|------------|------|
| T1 | 训练计划与周期 | 三分化、卧推周期、训练频率、RM/RPE 等计划编排内容。 | B 站可见材料集中在凯圣王三分化合作系列和既有三分化系列。 |
| T2 | 部位跟练与私教视角 | 胸肩三头、背/后束/二头、腿部、手臂等按部位组织的跟练或私教课。 | 本人账号与合作账号均有可核验公开视频。 |
| T3 | 动作技术与器械细节 | 卧推、推肩、罗马尼亚硬拉、高位下拉、器械夹胸等动作讲解。 | 多数锚点来自视频简介中列出的往期 BV 或搜索索引。 |
| T4 | 热身、拉伸与恢复 | 训练前热身、背部热身、拉伸、练后放松等降低受伤风险的内容。 | 本人账号可见拉伸视频；热身内容常嵌入跟练尾段或前段。 |
| T5 | 饮食、减脂与运动营养 | 三分化饮食、练后进食、减脂计划、碳水循环/轻断食等营养内容。 | 本人已有置顶减脂、宏量原则、一日饮食记录；合作饮食见凯圣王。正式入口 `content/nutrition/`。 |
| T6 | 赛事身份与背景 | IFBB PRO、自然古典健体、个人经历等背景信息。 | 仅作为来源判断辅助，不作为训练知识正文优先级。 |

## 缺口

- 抖音本人主页、抖音号与合集页需要本地浏览器或登录后确认；公开搜索只显示索引页和二级内容片段。
- 小红书、微信公众号未找到可核验的本人/官方主页，不能列为官方来源。
- B 站 HTML 页面 WebFetch 返回 412；本轮主要用搜索结果与 B 站公开 API 验证标题、owner、合集结构，未截图。
- 饮食/减脂类内容中“本人账号原创”与“合作账号/二创索引”的边界仍需细扫时复核。
